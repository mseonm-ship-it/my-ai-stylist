# 🐦 파랑새 스타일리스트 V2

파랑새 캐릭터를 메인 브랜드로 적용한 개인 AI 스타일리스트 MVP입니다.

### 포함 기능
- 파랑새 스타일리스트 캐릭터/브랜드 적용
- 홈 화면 아이콘
- PWA manifest
- 내 옷장 등록/삭제 및 브라우저 저장
- 쿨톤/웜톤/뉴트럴 설정
- 옷장 기반 3가지 코디 추천
- 어울림 점수
- 모바일 반응형
