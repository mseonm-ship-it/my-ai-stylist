# MY AI STYLIST 👕🎨

내 옷장을 우선으로 활용하는 개인 AI 스타일리스트 MVP입니다.

## 현재 기능
- 옷장 아이템 등록 / 삭제
- 색상과 이모지 표시
- 쿨톤 / 웜톤 / 뉴트럴 프로필
- 여름/겨울 쿨톤 등 세부 타입 선택
- 옷장 데이터를 브라우저 localStorage에 저장
- 3가지 코디 자동 생성
- 퍼스널 컬러 기반 어울림 점수
- 모바일 반응형 화면
- GitHub Pages에서 별도 서버 없이 실행 가능

## GitHub Pages 배포

1. GitHub에서 새 repository를 만듭니다.
2. `index.html`, `style.css`, `app.js`를 업로드합니다.
3. `Settings` → `Pages`
4. `Deploy from a branch`
5. Branch를 `main`, folder를 `/ (root)`로 선택
6. 저장하면 GitHub Pages 주소가 생성됩니다.

## 다음 개발 단계

1. 옷 사진 업로드
2. 사진에서 의류 종류/색상/핏 자동 인식
3. 실제 날씨 API 연결
4. 장소/일정 입력
5. AI에게 코디 생성 요청
6. 착장 사진 분석
7. 사용자별 선호도 학습
8. 구매 후보가 기존 옷과 2~3개 이상 조합되는지 자동 검사
9. 퍼스널 컬러 사진 분석
10. 코디 결과 이미지 생성

> 현재 버전의 점수는 실제 퍼스널 컬러 진단이 아니라 스타일 추천용 데모 점수입니다.
